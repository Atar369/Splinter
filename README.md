# Splinter

**Splinter** is a Unity 2D perspective-switching puzzle game about illness, empathy and learning.

This repository contains a playable source prototype covering:

- Joey's Lantern Market
- Sam's Silent Harbour
- Lin's Tilting Library
- Ray's Shifting Archive
- Kai's final confrontation with the Mask

## Run

1. Open the repository folder with Unity Hub.
2. Use Unity **2022.3 LTS** or newer.
3. In Unity, choose **Splinter > Generate Play Scene** from the menu.
4. Open `Assets/Scenes/Splinter.unity` and press Play.

The generated scene and runtime bootstrap keep the prototype portable and remove the need for imported sprite or font assets.

## Controls

- Use mouse or touch for choices.
- In the Tilting Library, hold **R** or **Up Arrow** to anchor yourself.

## Ethics and scope

These mechanics are deliberately simplified symbolic representations. They are not full simulations of real conditions, and the opening and ending state this clearly. Future development should involve clinicians and people with lived experience in chapter writing and accessibility review.
